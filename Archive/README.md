# Archive

Old code and documents kept for reference. Nothing in this folder is compiled, tested or shipped.

| Folder | What it was |
|---|---|
| `Engine/Source/Legacy/` | The first engine generation (old ECS, asset manager, Vulkan backend, old editor). Replaced by the current `Engine/Source` modules. |
| `Engine/Tests/Legacy/` | Tests for the code above. |
| `Docs/` | Design notes written before the current architecture (audio, editor, entity, renderer, events) and the old TODO list. |
| `IsItHardToPressTheJumpButton/` | Config left over from a removed sample game. |

Do not include anything from here in the build. If a piece is worth reviving, port it into the live tree with tests.
